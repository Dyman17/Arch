# 👤 Пользовательский сценарий

Как пользователь проходит по приложению от входа до результата.

## Основной флоучарт

```mermaid
flowchart TD
    A[Открыл приложение] --> B{Есть аккаунт?}
    B -- Да --> C[Ввёл логин/пароль]
    B -- Нет --> D[Регистрация]
    D --> C
    C --> E{Успех?}
    E -- Да --> F[Главная страница]
    E -- Нет --> C
    F --> G[Выбрал действие]
    G --> H[Результат]
```

## Экраны

| # | Экран | Описание |
|---|-------|----------|
| 1 | Логин | Ввод данных |
| 2 | Регистрация | Создание аккаунта |
| 3 | Главная | Основной экран |
| 4 | Результат | Вывод данных |
