Как ходит в API фронт (@yernurge). Полные JSON — в [backend.md](backend.md), общий процесс — в [README.md](README.md).

## База

- Base URL: `/api`. Всегда слать `lang` (`ru`/`en`/`kk`)
- `session_id` (uuid): один на сеанс, генерить при старте, слать в `voice`/`qr`
- Ничего не считать самому: `bearing_deg`, `distance_m`, `duration_min` — брать из ответов
- Во внешние API (routing/STT/LLM) напрямую не ходить, ключей во фронте нет

## Карта экранов → вызовы

| Экран | Вызовы по порядку |
|-------|-------------------|
| Старт | `GET config` → точка стелы, языки, таймауты |
| Idle / карта | `GET places?lang=` → точки |
| Каталог | `GET places?lang=&q=&categories=` — поиск и фильтры считает сервер, фронт шлёт и рисует |
| Карточка | `GET places/{id}` → детали |
| Маршрут | `GET places/{id}/route` → линия + мета + стрелка |
| Голос | `POST voice` → по ответу: карточка / список / сцена / повтор |
| TarihSky | `GET places/{id}/scene` → изображения + тексты |
| QR | `POST qr` → отрисовать `url`, таймаут 30 сек |
| Сброс | `POST session/end` (опц.) + локальный сброс |

## Обработка ошибок (обязательно)

| Ответ | Действие UI |
|-------|-------------|
| `200` | штатный экран |
| `404 PLACE_NOT_FOUND` на карточке | «место не найдено» → каталог |
| `404` на сцене | скрыть кнопку TarihSky (не показывать ошибку) |
| `422 SPEECH_UNRECOGNIZED` | error_speech: «повторите» + кнопка «выбрать на карте» |
| `503 AI_UNAVAILABLE` | то же, что 422 + пометка |
| `503 ROUTE_UNAVAILABLE` | повтор с `?fallback=1` → прямая + «примерный путь» |
| сеть упала | баннер + каталог из кэша |
| таймаут 90 сек | прощание → idle |

## Условные флаги (не игнорировать)

- `has_scene: false` → скрыть кнопку TarihSky
- `is_open_now: false` → бейдж «закрыто» + `opens_next`
- `access: transit` → способ поездки вместо пешего пути
- `is_approximate: true` → пометка «примерный путь»

## Моки до готовности бэка

Пока бэк не поднял seed — фронт работает на локальных моках **той же формы**, что в `backend.md`. Моки лежат в `frontend/src/mocks/`, удаляются после интеграции (не в `main`).
