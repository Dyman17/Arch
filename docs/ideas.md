# 💡 Идея проекта — BaGdar

> Кейс Smart City Aktau. **Решение: делаем BaGdar.** Остальное — запасные.

---

## ✅ Основная идея: BaGdar — цифровой гид по Актау и Мангистау

**Бағдар — интерактивный туристический гид по Актау и Мангистау в формате городской стелы.** Он помогает человеку на своём языке найти интересное место, понять, как туда добраться, и познакомиться с историей региона. Первая версия — прототип на базе ноутбука или мини-ПК с экраном, микрофоном и камерой.

### Основной пользовательский сценарий

1. Турист подходит к стеле и видит карту с предложением выбрать место или задать вопрос.
2. Нажимает кнопку микрофона и спрашивает на своём языке. Также может выбрать объект касанием.
3. Система распознаёт вопрос и язык, находит место в проверенном каталоге и выдаёт короткий ответ.
4. Карта плавно приближает объект, показывает маршрут от стелы, расстояние и примерное время в пути.
5. Крупная стрелка и текст объясняют, в какую сторону начать движение.
6. Турист сканирует QR-код и открывает маршрут на телефоне.

Точка установки и ориентация стелы задаются заранее. В первой версии направление показывается относительно стелы. Для объектов за пределами пешей доступности указывается подходящий способ поездки.

### Исторический режим TarihSky — «Тогда и сейчас»

Из карточки места турист открывает сравнение современного вида и исторической реконструкции. Ползунок позволяет плавно переходить между изображениями. Рядом — короткая историческая справка на выбранном языке.

Для демонстрации готовим 2–3 сцены заранее, желательно с одинаковым ракурсом изображений. ИИ отвечает на вопросы на основе проверенных материалов. Реконструкции обозначаются как художественные; их генерация в реальном времени в первую версию не входит.

### Объём первой версии

- Один район Актау и **10–20 проверенных объектов**
- Карта, карточки мест и поиск касанием
- Голосовой вопрос, определение языка и текстовый ответ
- Маршрут, расстояние, время и подсказка направления
- QR-код для продолжения навигации на телефоне
- «Тогда и сейчас» для 2–3 объектов
- Понятные состояния загрузки и ошибок, ручной выбор языка, возврат на главный после сеанса

**Не в v1:** фото с генерацией фона, погода, озвучивание, сложные жесты. Языки утвердить до разработки.

### Техническая основа

| Часть | Предложение | Ответственность |
|---|---|---|
| Frontend | React + TypeScript + Vite, MapLibre | Интерфейс стеллы, запись голоса, карта, карточки, ползунок, QR |
| Backend | Python + FastAPI | Каталог, речь, вопросы, ИИ, маршруты |
| Данные | Каталог + статические изображения | Координаты, описания, переводы, часы, источники, сцены |
| Оборудование | ПК/экран/микрофон; HuskyLens по готовности | Запуск, приветствие при подходе |

Маршрут и расстояние — из сервиса маршрутизации; ИИ — понимание запроса и формулировка. **Ключи внешних сервисов — только на сервере.**

### Порядок разработки

1. Утвердить точку, объекты, языки, демо-сценарий
2. Зафиксировать архитектуру, задачи, API в документации
3. Карта → карточка → маршрут → QR
4. Текстовый вопрос → затем голос
5. Исторические сцены и переходы
6. Приложение на устройстве + полный сценарий с людьми
7. HuskyLens, если основное стабильно

### Критерий готовности

Человек, который впервые видит стеллу, сам задаёт вопрос или выбирает место, понимает направление, открывает историческую сцену и получает маршрут на телефон. Демо на целевом устройстве; при ошибке речи основные действия доступны касанием.

### Главная демонстрация (питч)

Вопрос на языке туриста → карта и путь → TarihSky «Тогда и сейчас» → QR на телефон.

## 💭 Запасные идеи

### МестоLive — P2P-сеть обмена парковочными местами

Боль: час пик у набережной, «Дины», Aktau Mall — машины кружат впустую. Решение без железа: CV-камера видит выезд → заявка → первый в листе ожидания получает пуш, 2 минуты на подъезд. Рейтинг доверия вместо денег. MVP: карта Актау, симуляция, YOLO, очередь, таймер, дашборд акимата. Риски: приватность номеров, сложное демо из 4 частей.

### Осанка — скрининг позвоночника школьников

Камера 10 сек → метрики скелета → «риск сколиоза» (скрининг, не диагноз) + дашборд школ Актау. Плюсы: pose из коробки, неубиваемое демо. Минусы: медицинский формулинг, свет.
