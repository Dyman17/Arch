## 🚀 Быстрый старт (для всех)

### 1. Настройка (один раз)
```bash
git clone https://github.com/Dyman17/Arch.git
cd Arch

npm install
npm run dev
```

### 2. Правила Git
```
❌  НИКОГДА не пиши в main напрямую
✅  Каждая задача = отдельная ветка
✅  Перед началом работы: git pull origin main
✅  После готовности: открой PR, дождись ревью
```

### 3. Как работать
```bash
# Начало задачи
git checkout main
git pull origin main
git checkout -b feature/название-задачи

# Когда закончил
git add .
git commit -m "что сделал"
git push origin feature/название-задачи
# → открой PR на GitHub
```

## 📝 Когда придёт кейс

1. **Техлид** читает кейс → пишет `tasks.md` (разбивает на задачи)
2. **Все** смотрят `tasks.md` → берут свою задачу → создаёте ветку
3. **Техлид** создаёт флоучарты в `docs/`
4. Каждые 2-3 часа — синхронизация

---

## ⚡ Команды, которые нужны каждый день

```bash
git pull origin main          # обновиться перед работой
git checkout -b feature/xxx   # создать ветку
git add . && git commit -m ""  # закоммитить
git push origin feature/xxx    # запушить
gh pr create --fill            # создать PR
gh pr merge --squash           # замержить (делает техлид)
```

---

## 🚫 Запрещено

- Писать в `main` без PR
- Коммитить `.env`, ключи, пароли
- Удалять чужие коммиты
- Мержить свой PR без ревью техлида
